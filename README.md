# Bleskovka

Multiplayer kvíz v štýle Kahoot: hostiteľ vytvorí kvíz, hráči sa pripoja PIN kódom
a odpovedajú na otázky na čas. Ročníkový projekt.

- **Autori:** Teo Teplan, Jakub Klimo, Adrian Pagáč
- **Trieda:** 3.ATL
- **Cieľ projektu:** vytvoriť webovú aplikáciu na vedenie interaktívnych kvízov v triede
  (podrobnosti v `01_Poziadavky/zadanie.md`).

## Štruktúra projektu

| Adresár | Obsah |
|---|---|
| `01_Poziadavky/` | zadanie, roly, funkcionálne a nefunkcionálne požiadavky |
| `02_Analyza/` | use cases (a use case diagram) |
| `03_Navrh/` | ERD, schéma databázy, návrh rozhraní |
| `04_Implementacia/src/` | zdrojový kód |
| `05_Testovanie/` | testovacie scenáre a zistené chyby |
| `06_Dokumentacia/` | používateľská a inštalačná príručka |

## Postup spustenia aplikácie

Doplní sa po implementácii (bude súčasťou `06_Dokumentacia/instalacna-prirucka.docx`).
